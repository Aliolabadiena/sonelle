using the built-in mascot
orchestrator = the session you talk to; code-writer = the subagents that edit files. Applies to your next prompt.
To use a different TTS voice, edit sonelle.config.json:

  "narrator": {
    "engine": "edge",                  // kokoro (local) | edge (cloud) | sapi (offline)
    "voice": "en-US-AriaNeural",       // kokoro: af_heart, af_bella, ...
    "speed": 0.95
  }

This panel only SHOWS these keys - it does not change the voice itself.
